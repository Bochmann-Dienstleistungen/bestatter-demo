# Bestattungshaus-Demo — Variante A (handcodiert)

Self-contained Onepager + Kosten-Rechner. Kein Build-Tool, kein CMS.
Direkt per FTP oder GitHub Pages deploybar.

## Dateien
- `index.html` — Onepager, alle 10 Sektionen, CSS + JS inline
- `kosten.html` — Kosten-Rechner
- `impressum.html`, `datenschutz.html` — Rechtsseiten (§5 TMG, DSGVO)
- `img/` — 6 Bilder, self-hosted

## Datenschutz
- Schriften über bunny.net (DSGVO-freundlich, keine Logfiles) — kein Google Fonts
- Google Maps als Zwei-Klick-Lösung
- kein Tracking
